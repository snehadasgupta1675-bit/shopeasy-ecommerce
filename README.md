# ShopEasy - E-Commerce Product Catalog

ShopEasy is a responsive e-commerce product catalog developed as a Web Development Capstone Project.

## Features

* Product catalog with 6 products
* Product images and details
* Search and category filtering
* Product details page
* Add to cart functionality
* Remove items from cart
* Cart total calculation
* Responsive user interface
* Backend API for product data

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* JSON

## How to Run

### Frontend

Open `frontend/index.html` using VS Code Live Server.

### Backend

Open the terminal inside the `backend` folder and run:

```bash
npm install
node server.js
```

The backend API will run on the configured port.

## Project Objective

To build a modular e-commerce product catalog using modern web development technologies, with a structured frontend, backend API, product management, and shopping cart functionality.
